Ciclo 3 - Cálculo do IMC usando Python

Atividade de interface gráfica em Python. O programa calcula o IMC (Índice de Massa Corporal) do paciente a partir da altura e do peso e mostra a classificação.

Fiz a tela usando o Tkinter, que já vem junto com o Python, então não precisa instalar nada.
Pode usar vírgula ou ponto no peso, por exemplo 70,5 ou 70.5.
